# LINE CRM สะสมแต้ม (v2)

ระบบสะสมแต้มผ่าน LINE สำหรับร้านค้า **ใช้โค้ดชุดเดียวกับทุกร้าน** แต่ละร้านต่างกันแค่ไฟล์ตั้งค่าและชีตของร้าน

- **หน้าลูกค้า** (เปิดใน LINE): สมัครสมาชิก + ยอมรับ PDPA · บัตรสมาชิก + QR · แลกของรางวัล · คูปอง (แสดง QR ให้พนักงาน) · ประวัติแต้ม
- **หน้าพนักงาน**: สแกน QR / ค้นเบอร์ → บันทึกยอดซื้อ (ระบบคิดแต้มเอง) · ใช้คูปอง · ปรับแต้ม (เฉพาะผู้จัดการ) · รายการล่าสุด
- **หลังบ้าน**: Google Apps Script + Google Sheets ของแต่ละร้าน

## โครงสร้าง

```
index.html          หน้าลูกค้า (ทุกร้านใช้ร่วมกัน)
staff.html          หน้าพนักงาน
app/                โค้ดหน้าเว็บ (customer.js, staff.js และส่วนที่ใช้ร่วมกัน)
themes/             base.css (โครง) + ธีมสำเร็จรูป luxury.css, minimal.css
shops/shops.js      รายชื่อร้าน + โดเมนของแต่ละร้าน
shops/<ร้าน>/       config.js (ชื่อ สี ธีม LIFF ID URL หลังบ้าน ข้อความ) + โลโก้/รูป
vercel.json         กฎลิงก์: /<ร้าน> → หน้าลูกค้า, /<ร้าน>/staff → หน้าพนักงาน
code.gs             หลังบ้าน (วางใน Apps Script ของแต่ละร้าน — ไฟล์เดียวกันทุกร้าน)
tools/              เว็บทดสอบในเครื่อง + ชุดทดสอบอัตโนมัติ (ไม่ขึ้น Vercel)
```

ร้านถูกเลือกจาก **โดเมน** (เช่น `khamwan.com` ถ้าใส่ไว้ใน `shops/shops.js`) หรือจาก **ลิงก์** `/<ร้าน>` บนโดเมนหลัก

### ค่าของร้านอยู่ที่ไหน

| ค่า | อยู่ที่ | ใครแก้ |
|---|---|---|
| ชื่อร้าน สี โลโก้ ฟอนต์ ธีม ข้อความ LIFF ID URL หลังบ้าน | `shops/<ร้าน>/config.js` | เรา |
| อัตราแต้ม แต้มต้อนรับ ยอดสูงสุดต่อบิล อายุคูปอง รหัสนำหน้าสมาชิก | ชีต **Settings** ของร้าน | เรา / เจ้าของร้าน |
| ของรางวัล โปรโมชัน | ชีต **Rewards** / **Promotions** | เจ้าของร้าน |
| พนักงานและสิทธิ์ | ชีต **Staff** | เจ้าของร้าน |

กฎแต้มต้องอยู่ในชีต ไม่อยู่ใน config เพราะ Apps Script ต้องเป็นคนคิดแต้มเอง (ค่าที่อยู่ในหน้าเว็บ ใครเปิดดูโค้ดก็แก้ได้)

## ทดสอบในเครื่อง

LIFF ใช้กับ localhost ไม่ได้ หน้าเว็บในเครื่องจึง **จำลองผู้ใช้ LINE** แล้วคุยกับ **Apps Script ทดสอบของเราเอง**

1. สร้าง Google Sheet ทดสอบ → ส่วนขยาย → Apps Script → วาง `code.gs`
2. รันฟังก์ชัน `testSetup` (ขอสิทธิ์ + สร้างชีต) แล้วรัน `enableTestMode`
   > ⚠️ `enableTestMode` ใช้กับสคริปต์ทดสอบเท่านั้น **ห้ามรันในสคริปต์ของร้านจริง**
3. Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → คัดลอก URL `/exec`
4. ดับเบิลคลิก `เปิดเว็บทดสอบ LINE CRM.command` → กดปุ่ม **🧪 ทดสอบ** มุมซ้ายล่าง → วาง URL → บันทึก
5. สลับเป็น "พนักงานทดสอบ" ในแผงเดียวกัน แล้วเปิดหน้าพนักงาน → ในชีต Staff เปลี่ยน Status เป็น `ACTIVE`

ลิงก์ทดสอบ: `http://localhost:8002/khamwan` · `http://localhost:8002/khamwan/staff` · `http://localhost:8002/demo`

### ชุดทดสอบอัตโนมัติ (ไม่ต้องใช้ Google จริง)

```bash
node tools/test/gas-test.js          # ทดสอบ code.gs ทุกขั้นตอนบนชีตจำลอง
# ทดสอบหน้าเว็บผ่าน Chrome (เปิด 2 เซิร์ฟเวอร์ก่อน)
python3 tools/dev-server.py 8002 &
node tools/test/gas-server.js &
node tools/test/e2e.js               # ภาพหน้าจออยู่ใน tools/test/shots/
```

## ติดตั้งร้านใหม่ (checklist)

**1) Google (ใช้บัญชี Google ของร้าน — โควตาของ Apps Script จะได้ไม่หารกับร้านอื่น และร้านเป็นเจ้าของข้อมูลลูกค้า)**
- [ ] สร้าง Google Sheet → ส่วนขยาย → Apps Script → วาง `code.gs` → รัน `testSetup`
- [ ] ชีต Settings: กรอก `SHOP_NAME`, `LIFF_ID`, `MEMBER_PREFIX` (เช่น `KW`) และตรวจ `POINT_RATE_BAHT`
- [ ] Deploy เป็น Web app (Execute as: Me, Anyone) → เก็บ URL `/exec`
- [ ] แชร์ชีตให้เราเป็นผู้แก้ไข (ไว้ช่วยดูแล)

**2) LINE (ใน LINE Developers ใช้ provider เดียวกับ LINE OA ของร้าน — LINE ให้รหัสผู้ใช้คนละชุดในแต่ละ provider)**
- [ ] สร้าง LINE Login channel → เพิ่ม LIFF app
  - Endpoint URL: `https://<โดเมนหลัก>/<ร้าน>` (หรือ `https://<โดเมนร้าน>` ถ้ามีโดเมนแล้ว)
  - Scopes: `openid` + `profile` · เปิด **Scan QR** (หน้าพนักงานใช้กล้องของแอป LINE)
- [ ] ลิงก์ลูกค้า: `https://liff.line.me/<LIFF ID>` → ใส่ใน Rich menu ของ LINE OA
- [ ] ลิงก์พนักงาน: `https://liff.line.me/<LIFF ID>/staff` → ส่งให้พนักงานเป็นการส่วนตัว (ไม่ใส่ใน Rich menu)

**3) หน้าเว็บ**
- [ ] ก๊อปโฟลเดอร์ `shops/demo` เป็น `shops/<ร้าน>` แล้วแก้ `config.js` (ชื่อ ธีม สี `liffId` `apiUrl` นโยบายความเป็นส่วนตัว) + ใส่โลโก้
- [ ] เพิ่มร้านใน `shops/shops.js`
- [ ] ขึ้น Vercel

**4) เปิดใช้**
- [ ] เจ้าของร้านเปิดลิงก์พนักงาน → ในชีต Staff เปลี่ยนแถวของตัวเองเป็น `Status = ACTIVE`, `Role = OWNER`
- [ ] พนักงานคนอื่นเปิดลิงก์พนักงาน → เจ้าของร้านอนุมัติในชีต (`CASHIER` = บันทึกยอด/ใช้คูปอง, `ADMIN`/`OWNER` = ปรับแต้มได้ด้วย)
- [ ] ร้านต้องใส่นโยบายความเป็นส่วนตัวของจริงใน config (`legal`) — ข้อความในตัวอย่างเป็นแค่แม่แบบ

## อัปเดตโค้ด
- **หน้าเว็บ**: อัปขึ้น Vercel ครั้งเดียว ทุกร้านได้พร้อมกัน → ทดสอบกับร้านทดลองก่อนเสมอ
- **code.gs**: วางทับในทุกร้าน → Deploy → Manage deployments → แก้ deployment เดิม → Version: New version (URL เดิมไม่เปลี่ยน) แล้วรัน `testSetup` อีกครั้งถ้ามีคอลัมน์ใหม่ (รันซ้ำได้ ไม่ลบข้อมูล)

## เพิ่มโดเมนให้ร้าน
1. เพิ่มโดเมนในโปรเจค Vercel + ตั้ง DNS
2. ใส่โดเมนใน `shops/shops.js` → `domains: ['khamwan.com']`
3. เปลี่ยน Endpoint URL ของ LIFF เป็น `https://khamwan.com`

ลิงก์ `liff.line.me/...` ใน Rich menu ไม่ต้องเปลี่ยน

## ยังไม่ได้ทำ (ตามแผน)
- หลังบ้านเจ้าของร้าน (ตอนนี้แก้รางวัล/โปรโมชัน/พนักงานในชีต)
- ระดับสมาชิก · แต้มหมดอายุ · สิทธิ์วันเกิด · แนะนำเพื่อน · ส่งข้อความ LINE
- ชีต Transactions ใหญ่มาก (หลายหมื่นแถว) จะเริ่มช้า → ย้ายข้อมูลปีเก่าไปชีตเก็บถาวร
